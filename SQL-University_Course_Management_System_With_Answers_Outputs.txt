=============================================================================

SQL Answer:

QUESTION 12: SUBQUERY - STUDENTS IN COURSES WITH MORE THAN 10
STUDENTS
=============================================================================

SQL Answer:
SELECT DISTINCT s.StudentID, s.FirstName, s.LastName
FROM Students AS s
JOIN Enrollments AS e ON e.StudentID = s.StudentID
WHERE e.CourseID IN (
    SELECT CourseID
    FROM Enrollments
    GROUP BY CourseID
    HAVING COUNT(DISTINCT StudentID) > 10
);

MySQL-style output:
Empty set

Explanation:
No course has more than 10 enrolled students in the supplied sample data.

QUESTION 15: RUNNING TOTAL OF ENROLLMENTS
=============================================================================

SQL Answer:
SELECT EnrollmentID, StudentID, CourseID, EnrollmentDate,
       COUNT(*) OVER (
           ORDER BY EnrollmentDate, EnrollmentID
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS RunningTotalEnrollments
FROM Enrollments
ORDER BY EnrollmentDate, EnrollmentID;

QUESTION 16: LABEL STUDENTS SENIOR OR JUNIOR
=============================================================================

SQL Answer:
SELECT StudentID, FirstName, LastName, EnrollmentDate,
       CASE
           WHEN EnrollmentDate < DATE_SUB(CURDATE(), INTERVAL 4 YEAR)
               THEN 'Senior'
           ELSE 'Junior'
       END AS StudentLevel
FROM Students
ORDER BY StudentID;
